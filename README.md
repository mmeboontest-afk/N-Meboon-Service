# N'Meboon Minecraft Bot (Mineflayer) + AI Control Panel

แยกเป็น Render service **ใหม่ต่างหาก** จากเว็บ/บอท Discord เดิม เพื่อไม่ให้ CPU ชนกัน (บอทเล่นเกมกิน CPU เยอะกว่าบอท Discord ธรรมดามาก)

## ⚠️ ทดสอบได้แค่ไหนจริงๆ — พูดตรงๆ ก่อนใช้งาน
- **Decision logic (`modes/custom1.js`)** — ทดสอบเต็มที่แล้ว 15 เคส (ลำดับความสำคัญ: หนีตาย > เก็บของตอนตาย > เก็บของระหว่างทาง > เดินทาง > ทำอาหาร > เก็บของ > ล่าสัตว์ > ว่าง) ถูกต้องตามที่สั่งทุกข้อ
- **เว็บควบคุม + API (`server.js`)** — ทดสอบเต็มที่ 11 เคสผ่าน HTTP จริง ยืนยันแล้วว่า **จะไม่มีทาง connect เข้าเกมได้เลยถ้ายังไม่ตั้งค่าในเว็บก่อน** ตามที่ขอ
- **ระบบความจำไฟล์ TXT ใน Discord (`memory.js`)** — ทดสอบเต็มที่ ทั้ง save/load/round-trip และกรณีช่องว่างเปล่า (เริ่มใหม่)
- **ส่วนที่เชื่อม Mineflayer จริง (`modes/custom1Runner.js`)** — **ยังไม่ได้ทดสอบกับเซิร์ฟเวอร์ Minecraft จริงเลย** เพราะในสภาพแวดล้อมที่ผมเขียนโค้ดนี้ไม่มีเซิร์ฟเวอร์ Minecraft ให้ต่อ ส่วนนี้คือ: pathfinding จริง, จังหวะกระโดดตี (crit timing), การตรวจจับมอนสเตอร์/สัตว์ ทำตาม mineflayer/mineflayer-pathfinder API ที่ถูกต้องตามเอกสาร แต่ **ต้องรอคุณรันจริงแล้วบอกกลับมาว่าตรงไหนต้องปรับ** (เช่น ระยะกระโดด, จังหวะตี, การเล็งเป้า)
- **การทำอาหาร + เก็บของเข้ากล่อง** — ยังเป็นแค่ log ข้อความ ("Cooking...", "Depositing...") ยังไม่ได้ implement การเปิดเตาเผา/หีบจริง เพราะต้องรู้ตำแหน่ง/ทิศทางที่แน่นอนของเตา+หีบที่คุณสร้างไว้ที่พิกัด -1371 77 1611 ก่อน — บอกมาได้เดี๋ยวต่อให้ครบ (เช่น เตาอยู่ทิศไหนของหีบ มีกี่เตา)

## วิธี Deploy
1. สร้าง repo ใหม่บน GitHub (แยกจาก repo เดิม) อัปไฟล์ทั้งหมดในนี้ขึ้นไป
2. Render → New → Web Service → เลือก repo นี้
3. Build Command: `npm install`  / Start Command: `npm start`
4. Environment variables:
   - `MAIN_DISCORD_TOKEN` = **ใช้ token เดียวกับบอทหลัก** (คัดลอกมาจาก service เดิมได้เลย ไม่ชนกันเพราะตัวนี้ไม่ได้ต่อ gateway ใช้แค่ REST API ส่งไฟล์)
   - `MEMORY_CHANNEL_ID` = `1492851614095118466` (ใส่ไว้แล้วเป็นค่า default ไม่ใส่ก็ได้)
5. Deploy เสร็จแล้วเข้า `https://<service-ของคุณ>.onrender.com/ai-control`

## วิธีใช้งาน
1. กรอก Server Host / Port / ชื่อบอท / เลือกโหมด (ตอนนี้ใช้งานได้จริงแค่ **Custom 1** โหมดอื่นเป็น placeholder รอทำต่อ) → กด **Save Config**
2. กด **▶ Start** — บอทจะ connect เข้าเกม **ก็ต่อเมื่อกดปุ่มนี้หลัง Save Config สำเร็จแล้วเท่านั้น** ตามที่ขอ
3. ดูสถานะ/log สดได้ในหน้าเดียวกัน รีเฟรชอัตโนมัติทุก 3 วิ
4. กด **⏹ Stop** เมื่อไหร่ก็ได้ บอทจะออกจากเกมและบันทึกความจำทันที

## Custom 1 โหมดทำอะไรบ้าง (ตามลำดับความสำคัญ)
1. **หนีตาย** — ถ้ามีซอมบี้/กระดูกอยู่ใกล้ (≤12 บล็อก) สู้ก่อนเรื่องอื่นเสมอ
2. **ตายแล้ว** — กลับไปจุดตายล่าสุดเพื่อเก็บของคืน (จำพิกัดไว้อัตโนมัติ)
3. **ระหว่างเดินทาง** — เดินสปรินต์+กระโดดไปพิกัด -1371 77 1611 ถ้าเจอของตกอยู่ใกล้ๆ (≤6 บล็อก) จะแวะเก็บก่อน
4. **ถึงที่หมายแล้ว** — ถ้ามีเนื้อดิบ → ทำอาหารก่อน ถ้ามีเนื้อสุก → เก็บเข้ากล่อง ถ้าไม่มีอะไรต้องทำ → ไปล่าหมู/วัว/แกะ/ไก่ตัวที่ใกล้ที่สุด (ไม่ยุ่งกับสัตว์อื่น เช่น villager)
5. **ไม่มีอะไรทำ** → รอเฉยๆ

## ความจำ (ไฟล์ TXT ในช่อง Discord)
ทุกครั้งที่สถานะเปลี่ยน (เช่น เปลี่ยนจาก "เดินทาง" เป็น "ล่าสัตว์") บอทจะส่งไฟล์ `memory.txt` ใหม่ไปที่ช่อง `1492851614095118466` ทับของเก่า (หน่วงไว้ 3 วินาทีกันส่งถี่เกินไป) เปิดอ่านในช่อง Discord ได้เลยว่าตอนนี้บอทคิดอะไรอยู่ เก็บอะไรไว้บ้าง ถ้าช่องนี้ถูกลบไฟล์ล่าสุดทิ้งหมด บอทจะเริ่มนับหนึ่งใหม่ตามที่ขอ

## ยังไม่ได้ทำ (รอคิวถัดไป)
- โหมด Survival (เรียนรู้), PVP, Farming — ตอนนี้กดเลือกได้แต่บอทจะบอกว่า "ยังไม่พร้อม" เฉยๆ
- การเปิดเตาเผา/หีบจริงใน Custom 1 (รอข้อมูลตำแหน่งเตา/หีบที่แน่นอน)
- สกิน/ชื่อบอท: ชื่อตั้งผ่านเว็บได้แล้ว (ช่อง Bot Name) ส่วนเรื่องสกินข้อความที่ส่งมาตัดจบกลางคัน ("ฉันอยากให้มัน...") รอบอกต่อว่าต้องการแบบไหน
